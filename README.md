# 맞벌이 연말정산 시뮬레이터

부부의 총급여와 지출(카드·의료비·교육비·보험·연금저축·주택·기부금·부양가족)을 입력하면
**누구 명의로 얼마씩 몰아야 부부 합산 세금(소득세+지방소득세)이 최소가 되는지** 계산하고,
그 이유를 전략 가이드로 보여주는 웹앱입니다. 2026년 귀속(2027년 1~2월 정산) 근로소득 기준입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 세법 계산·최적화 단위 테스트
npm run build    # dist/ 정적 파일 (어느 웹서버에나 배포 가능)
```

## 기능

- **현재 vs 최적 비교**: 지금 각자 쓰는 대로 정산했을 때와 최적 배분 시의 결정세액·지방세·절세액
- **추천 배분표**: 카드 종류별 사용액, 부부 각자의 의료비 결제자, 기부금 명의, 부양가족(자녀·부모) 공제자, 세대주
- **전략 가이드**: 항목별 절세액, 한계세율 비교, 카드 최저사용금액·한도 도달 여부, 의료비 3% 문턱,
  소멸되는 세액공제 경고, 연금저축·IRP 추가 납입 효과
- **카드 배분 시뮬레이션 그래프**: 카드 사용 비중(남편 0~100%)에 따른 부부 합산 세금 곡선
- **상세 계산표**: 근로소득공제 → 과세표준 → 산출세액 → 세액공제 → 결정세액 전 과정
- 입력값은 브라우저(localStorage)에 자동 저장

## 화면 구성

1. **맨 위 추천 보드** — 입력하자마자 현재 vs 최적 세금, 절세액, "이렇게 하세요" 순서 목록
2. **입력** — ① 소득(총급여·월급 도우미·기납부세액 추정) → ② 올해 예상 지출(카드 총액 + 소비 성향 칩) → ③ 가족
3. **결과 탭**
   - 지출 플랜: 각자 카드·의료비·연금이 문턱/한도의 어디쯤인지, 카드 총지출 규모 × 소비 성향(신용 위주/체크 위주/혼합)별 추천 명의 분배
   - 추천 배분 / 전략 가이드 / 상세 계산

## 소득은 무엇을 넣나

- **총급여**: 원천징수영수증의 ‘총급여’(지급총액 − 비과세). 월급으로 추정할 땐 ‘월급으로 계산’ (식대 비과세 월 20만원 한도 반영)
- **기납부세액**: 12월 급여명세서의 소득세 누계 또는 홈택스 연말정산 미리보기 값. 모르면 ‘간이세액표로 추정’
- 원천징수 비율(80/100/120%)은 월 실수령액만 바꾸고 **최종 세금은 같다** — 환급·추가납부 금액만 달라짐

## 배포와 데이터 저장

서버·DB 없이 **정적 사이트**로 동작하며 입력값은 브라우저(localStorage)에만 저장됩니다.

- GitHub Pages: 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정하면 `main` 푸시 때마다 자동 배포(`.github/workflows/pages.yml`)
- 기기 이동·백업: ‘저장/불러오기’(JSON), 배우자와 공유: ‘링크 공유’(입력값이 주소 # 뒤에 담김, 서버를 거치지 않음)

## 구조

| 파일 | 역할 |
|---|---|
| `src/tax/rules.ts` | **모든 세법 수치** (세율, 한도, 공제율). 법이 바뀌면 이 파일만 수정 |
| `src/tax/engine.ts` | 한 사람의 연말정산 계산 (항목별 공제와 표준세액공제 중 유리한 쪽 자동 선택) |
| `src/tax/household.ts` | 부부 배분(Allocation) → 각자 입력으로 변환, 합산 평가 |
| `src/tax/optimizer.ts` | 최적 배분 탐색: 부양가족·세대주는 전수조사, 금액 항목은 다중 시작점 좌표하강법 |
| `src/tax/strategy.ts` | 결과를 설명하는 전략 문구 생성 |
| `src/components/*` | 입력 폼, 결과 패널, 그래프 |

## 반영한 규칙 (요약)

- 근로소득공제, 기본세율 6~45%, 근로소득세액공제 및 총급여별 한도
- 인적공제: 기본 150만, 경로(70세+) 100만, 장애인 200만, 부녀자 50만
- 신용카드 등: 총급여 25% 최저사용금액(신용카드→체크·현금→문화→전통시장→대중교통 순 차감),
  공제율 15/30/30/40/40%, **자녀 수별 기본한도**(7천 이하 300/350/400만, 초과 250/275/300만), 추가한도 300/200만
- 의료비: 총급여 3% 초과분 15%, 일반 부양가족 700만 한도, 본인·65세+·6세 이하·장애인 한도 없음,
  **배우자 의료비는 소득과 무관하게 결제한 배우자가 공제**
- 교육비 15% (취학전·초중고 300만, 대학 900만, 본인 무제한), 보장성보험 12% (100만)
- 연금계좌 600/900만, 15%(총급여 5,500만 이하)/12%
- 월세 17/15% (1,000만), 주택청약 40% (300만), 전세대출 원리금 40% (청약 합산 400만), 주담대 이자
- 자녀세액공제 25/30/40만 (**9세 이상**), 출산 30/50/70만, 결혼세액공제 50만
- 기부금: 일반 15/30%, 정치자금·고향사랑 10만까지 100/110, 고향사랑 10만~20만 40%
- 지방소득세 10%

## 한계와 확인할 점

- **근로소득만** 있는 경우를 가정합니다 (사업·금융소득 등 종합소득 합산 없음).
- 부양가족은 소득 요건(연 소득금액 100만원 이하)을 충족한다고 가정합니다.
- 4대보험 자동 추정치는 2026년 요율 기반 근사값입니다. 정확한 금액은 원천징수영수증으로 직접 입력하세요.
- `rules.ts`에서 `verify: true`로 표시한 값(자녀 수별 카드 한도, 자녀세액공제 연령, 고향사랑 구간 공제율)은
  언론 보도·개정안 기준입니다. 국세청 공식 안내로 확인한 뒤 필요하면 수정하세요.
- 기부금 소득 대비 한도는 일반기부금 30%로 단순화했고, 종교단체 10% 한도, 이월공제, 난임시술비,
  중소기업 취업자 감면, 한부모 공제는 반영하지 않았습니다.
- 월세·전세대출은 세대주가 공제받는 것으로 단순화했습니다.

모의 계산이므로 실제 신고 전에는 홈택스 「연말정산 미리보기」로 확인하세요.
